# Verification methodology

The editable verification-method vocabulary includes Test, Analysis,
Inspection, Demonstration, Simulation, Certification, Similarity, and Review
of design.

The verification matrix shows requirement, method, test, evidence, and status. A gap is explicit when no test or evidence is linked. Verification cases expose an editable method (Test, Analysis, Inspection, or Demonstration), objective, preconditions, procedure, expected and actual result, owner, environment, version, and baseline fields. Users can create a test/evidence pair and explicitly attach an evidence package through a canonical produces relationship; the sample does not claim that planned tests have executed.
