# Export system

Project JSON bundles include saved Diagram Studio perspectives alongside
artifacts, relationships, histories, framing, and baselines, so exported views
remain recoverable with the model.

JSON exports preserve the current versioned project bundle, including optional artifact history snapshots and lifecycle baselines, and Mermaid exports preserve a text representation of canonical relationships. Imported JSON is validated for schema version, unique artifact IDs, relation endpoints, optional history entries, and baseline records, then held in a review preview before it can replace the working copy; applying it is an audited transaction and remains undoable. Baseline comparison packages include both selected frozen snapshots and their canonical artifact/relationship diff. SVG and PNG exports are generated from the same canonical relationship set. The full-graph SVG uses a bounded grid layout and includes offscreen canonical content. SVG exports accept a title and optional legend; PNG exports accept 1x, 2x, 3x, or 4x scale with dark, light, or transparent backgrounds. Very large raster requests are bounded to a browser-safe 8192-pixel maximum dimension; the SVG remains the lossless full-size export. Mermaid source can be downloaded as `.mmd`, embedded in Markdown, copied as source, or copied as fenced Markdown when browser permission is available. The export strip also provides complete requirements, traceability, and verification CSVs, a Markdown engineering report, and a printable HTML report. CSV values are escaped for spreadsheet compatibility and report content is derived from canonical artifacts and relationships.
