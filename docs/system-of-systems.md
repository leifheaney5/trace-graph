# System of systems

The application vocabulary reserves a profile for constituent systems, missions, capabilities, ownership, and cross-system dependencies. The SoSE architecture profile provides canonical mission-thread, system-of-systems context, capability-to-system allocation, operational dependency, interoperability, and cascading-impact views. Cascading impact follows canonical constituent-system `depends-on` links and derives affected capabilities and missions through `represents`, `allocated-to`, and `requires` relationships. These views derive IDs and table cells from the shared artifact and relationship model rather than copying data into a separate diagram store. The constituent inspector supports editing persisted ownership, authority, operational-independence, managerial-independence, lifecycle, and availability attributes. Richer emergent-behavior and evolution analysis remains future work.
