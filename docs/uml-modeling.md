# UML modeling

UML is represented by profile-driven use-case, class, component, deployment, sequence, and state-machine views over the same canonical model. Capability artifacts become use-case nodes, the first stakeholder is shown as the canonical actor, and relationship counts are derived from shared model links. The architecture inspector can create a canonical actor-to-use-case `uses` relationship. Each projection retains canonical IDs and uses simplified notation; standards-complete UML semantics remain roadmap work.
