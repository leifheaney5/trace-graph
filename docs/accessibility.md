# Accessibility

The MVP uses semantic buttons, form labels, keyboard focus styling, status text, an accessible table, and a text summary beside the SVG trace. Playwright runs axe checks against the landing page and workbench for critical and serious violations. The app supports persisted dark/light themes, print styling, reduced-motion media behavior, high-contrast focus treatment, and non-drag relationship controls. Screen-reader certification and a full WCAG conformance audit are not claimed.
