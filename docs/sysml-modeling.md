# SysML modeling

The architecture profile provides canonical SysML requirements, block-definition, internal-block, activity, sequence, state-machine, allocation, and context views. It demonstrates system-of-interest containment, allocations, interface ownership, and derived behavior summaries from canonical capability, relationship, and status data. Users can allocate a requirement to a block and create an interface with ownership and connection relationships from the inspector. Diagram Studio can also create canonical practical-subset elements including parts, ports, activities, actions, states, packages, and item-flow-oriented elements, while retaining their IDs in saved perspectives and exports. Full standards-complete requirement, activity, sequence, state, and parametric diagram authoring remain planned.
